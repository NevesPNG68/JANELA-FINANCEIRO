# JANELA FINANCEIRO

Painel de inteligência financeira do Janela.

- `index.html`: aplicação web.
- `ESTRUTURA JANELA_V02.xlsx`: base financeira lida diretamente pelo navegador.

## Atualização da base

Para atualizar o painel, substitua a planilha no repositório mantendo exatamente o nome `ESTRUTURA JANELA_V02.xlsx`. O painel busca a versão mais recente sem cache.

A aplicação foi preparada para GitHub Pages e utiliza a planilha do próprio repositório como fonte de dados.
